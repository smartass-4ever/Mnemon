**Mnemon** is a Python execution cache for LLM agents — it cuts token costs by 93% by caching what your agent has already figured out, so repeat runs skip the LLM entirely.

Works with LangChain, LangGraph, CrewAI, AutoGen, Anthropic SDK, OpenAI SDK, and Google Generative AI. Zero code changes required.

```bash
pip install mnemon-ai
```

```python
import mnemon
mnemon.init()
# your existing code — completely unchanged
```
