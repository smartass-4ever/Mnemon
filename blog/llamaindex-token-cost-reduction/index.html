LlamaIndex is my go-to for RAG pipelines. I built an internal knowledge base query engine — hundreds of documents, structured queries, solid retrieval. But after putting it into production, I noticed the same handful of questions accounted for 70% of the API spend.

The problem: LlamaIndex has no cross-session query cache. Every query_engine.query() call retrieves context, synthesizes an answer, and bills you — even if you answered the exact same question yesterday. LlamaIndex's built-in caching helps with embeddings, but the LLM synthesis step runs fresh every time.

Where LlamaIndex costs pile up

  • Repeated queries over a static or slowly-changing knowledge base
  • FAQ-style workloads where 20% of questions drive 80% of volume
  • Scheduled document summarization over the same corpus
  • Agent workflows that query the same index multiple times

Execution-level caching with Mnemon

Mnemon caches the complete query execution — retrieval plan plus synthesized answer — and replays it on semantically equivalent future queries.

pip install mnemon-ai
import mnemon
m = mnemon.init()

from llama_index.core import VectorStoreIndex, SimpleDirectoryReader

documents = SimpleDirectoryReader("./docs").load_data()
index = VectorStoreIndex.from_documents(documents)
query_engine = index.as_query_engine()

def run_query(goal, inputs, *_):
    response = query_engine.query(inputs["question"])
    return str(response)

result = m.run(
    goal="answer question from knowledge base",
    inputs={"question": "What is our refund policy for enterprise customers?"},
    generation_fn=run_query,
)

print(result["output"])         # synthesized answer
print(result["tokens_saved"])   # tokens saved this run
print(result["cache_level"])    # "system1" | "system2" | "miss"

Second query with the same or similar question: 2.66ms, zero tokens, zero synthesis cost.

With LlamaIndex agents

import mnemon
m = mnemon.init()

from llama_index.core.agent import ReActAgent
from llama_index.core.tools import QueryEngineTool

query_tool = QueryEngineTool.from_defaults(query_engine=query_engine)
agent = ReActAgent.from_tools([query_tool])

def run_agent(goal, inputs, *_):
    return str(agent.chat(inputs["message"]))

result = m.run(
    goal="answer enterprise support question",
    inputs={"message": "How do I upgrade my enterprise plan?"},
    generation_fn=run_agent,
)

How matching works

System 1 — Exact match: Identical query text → cached answer in ~2.66ms, zero tokens.

System 2 — Semantic match: "What's your refund policy?" and "How do refunds work for enterprise?" are the same intent. Mnemon matches them and returns the cached answer — only paying for genuinely new questions.

System 2 requires embeddings: pip install mnemon-ai[full] or set an API key. This works alongside LlamaIndex's own embedding index — they cache different things.
