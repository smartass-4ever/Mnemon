AWS Bedrock is the enterprise choice for teams already in the AWS ecosystem — managed access to Claude, Llama, Titan, and more, with IAM, VPC, and compliance built in. I run a Bedrock-backed document processing pipeline for a regulated industry workflow. Everything is solid architecturally — but the per-token costs on recurring document types were climbing well beyond what was necessary.

The issue: Bedrock's invoke_model is stateless. Every invocation is a fresh cold start. The same contract classification, the same compliance check — full foundation model cost every time.

Where Bedrock costs accumulate

  • Document classification and extraction over recurring templates
  • Compliance checking agents that re-evaluate the same rule sets
  • Scheduled Bedrock Agents workflows running on recurring inputs
  • Knowledge base queries over stable document corpora

Execution-level caching with Mnemon

pip install mnemon-ai
import mnemon
import boto3, json

m = mnemon.init()
bedrock = boto3.client("bedrock-runtime", region_name="us-east-1")

def run_bedrock(goal, inputs, *_):
    body = json.dumps({
        "anthropic_version": "bedrock-2023-05-31",
        "max_tokens": 1024,
        "messages": [{"role": "user", "content": f"{goal}: {inputs['document']}"}]
    })
    response = bedrock.invoke_model(
        modelId="anthropic.claude-sonnet-4-6-20250514-v1:0",
        body=body
    )
    return json.loads(response["body"].read())["content"][0]["text"]

result = m.run(
    goal="classify and extract key fields from contract",
    inputs={"document": "Service Agreement between Acme Corp and Beta Ltd..."},
    generation_fn=run_bedrock,
)

print(result["output"])
print(result["tokens_saved"])
print(result["cache_level"])

Second invocation with same or similar document: 2.66ms, zero Bedrock tokens, $0.00.
