Google Gemini — particularly Gemini 1.5 Pro with its 1M context window — is powerful for long-document analysis. I use it for a pipeline that processes large codebases and generates review summaries. Excellent results, but at Gemini Pro pricing, recurring runs on the same codebase were adding up fast.

The problem: Gemini has no cross-session execution memory. Every generate_content() call starts fresh. The same codebase review, the same document summary — full price every run.

Where Gemini costs accumulate

  • Long-context analysis over documents that change slowly
  • Scheduled agents running recurring generation tasks
  • Multimodal pipelines processing similar images or documents
  • LangChain workflows backed by Gemini models

Execution-level caching with Mnemon

pip install mnemon-ai
import mnemon
import google.generativeai as genai

m = mnemon.init()
genai.configure(api_key="your-api-key")
model = genai.GenerativeModel("gemini-1.5-pro")

def run_analysis(goal, inputs, *_):
    response = model.generate_content(f"{goal}:\n{inputs['content']}")
    return response.text

result = m.run(
    goal="summarize code review findings",
    inputs={"content": "Module: auth.py\nChanges: added JWT validation..."},
    generation_fn=run_analysis,
)

print(result["output"])
print(result["tokens_saved"])
print(result["cache_level"])

Second call with same or similar input: 2.66ms, zero Gemini tokens, $0.00.
