Claude is among the most capable models available — Claude Sonnet in particular has become a production workhorse for AI applications. But at $3–$15 per million tokens depending on the model, costs compound fast at scale.

Here are the techniques that actually reduce your Anthropic bill, ranked by impact.

Technique 1: Cache execution results (biggest win)

The most expensive line on your Anthropic bill is almost always recurring work — agents that process the same types of inputs repeatedly, workflows that run on a schedule, pipelines that see the same question patterns daily.

Execution caching remembers what your agent produced for a given input and returns it instantly on the next similar call — zero tokens, zero API cost.

import mnemon
m = mnemon.init()

import anthropic
client = anthropic.Anthropic()

def run_analysis(goal, inputs, *_):
    message = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=1024,
        messages=[{"role": "user", "content": f"{goal}:\n{inputs['data']}"}]
    )
    return message.content[0].text

result = m.run(
    goal="summarize weekly engineering metrics",
    inputs={"data": "PRs merged: 14. Incidents: 0. Deploy frequency: 3.2/day."},
    generation_fn=run_analysis,
)

print(result["output"])         # summary
print(result["tokens_saved"])   # tokens saved vs full API call
print(result["cache_level"])    # "system1" | "system2" | "miss"

Impact: 93% cost reduction on recurring workloads. The second time any similar input is processed, it costs nothing.

Technique 3: Enable prompt caching

Anthropic's prompt caching caches up to 90% of your input tokens at 10% of the normal input price. If your system prompt is large and static, this is significant.

import anthropic
client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    system=[
        {
            "type": "text",
            "text": LARGE_STATIC_SYSTEM_PROMPT,
            "cache_control": {"type": "ephemeral"}  # cache this block
        }
    ],
    messages=[{"role": "user", "content": user_message}]
)

Impact: 90% reduction on system prompt tokens after the first call in a session. Requires prompts of 1024+ tokens to activate.

Technique 4: Trim output length

Output tokens cost 5× more than input tokens on most Claude models. Be explicit about desired output length:

# Instead of open-ended prompts:
"Analyze this document and give me your thoughts."

# Constrain the output explicitly:
"Summarize in 2-3 sentences. Be direct — no preamble."

Impact: 30–70% reduction on output token costs for verbose workflows.

Technique 5: Batch API for async workloads

Anthropic's Message Batches API processes requests asynchronously at 50% of standard price. For non-real-time jobs — nightly reports, bulk classification, document processing queues — this is free savings.

import anthropic
client = anthropic.Anthropic()

batch = client.messages.batches.create(requests=[
    {"custom_id": f"item-{i}", "params": {"model": "claude-haiku-4-5", ...}}
    for i, item in enumerate(items)
])

Impact: 50% across the board for any async workload.
