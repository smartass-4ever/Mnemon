Pydantic AI is fantastic for structured agent outputs — type-safe, clean, production-ready. I use it for a document processing pipeline that classifies and extracts data from incoming contracts. Clean code, but after two months in production, the bill was adding up fast.

The problem: every agent.run_sync() call is a cold start. Pydantic AI has no built-in execution memory. The same contract template — seen hundreds of times — triggers the full LLM reasoning loop every single run.

Where Pydantic AI costs accumulate

  • Structured extraction agents processing repeated document templates
  • Classification agents that see the same category patterns daily
  • Validation agents that re-check the same rule sets
  • Multi-turn agents that re-establish context on every session

Pydantic AI's type enforcement means your structured outputs are reliable — but you're paying full price to regenerate the same JSON schema outputs over and over.

Execution-level caching with Mnemon

Mnemon wraps your Pydantic AI agent calls and caches complete executions — including structured outputs — for replay on similar future inputs.

pip install mnemon-ai
import mnemon
m = mnemon.init()

from pydantic_ai import Agent
from pydantic import BaseModel

class ContractSummary(BaseModel):
    party_a: str
    party_b: str
    contract_type: str
    key_terms: list[str]

agent = Agent(
    'openai:gpt-4o',
    result_type=ContractSummary,
    system_prompt='Extract structured data from legal contracts.',
)

def extract_contract(goal, inputs, *_):
    result = agent.run_sync(inputs["text"])
    return result.data.model_dump_json()

cached = m.run(
    goal="extract contract parties and terms",
    inputs={"text": "This agreement between Acme Corp and Beta Ltd..."},
    generation_fn=extract_contract,
)

print(cached["output"])        # JSON-serialized ContractSummary
print(cached["tokens_saved"])  # tokens saved this run
print(cached["cache_level"])   # "system1" | "system2" | "miss"

Second run with an identical or structurally similar contract: 2.66ms, zero tokens, zero cost.

How matching works

System 1 — Exact match: SHA-256 fingerprint of the full input. Same contract text → cached result in ~2.66ms.

System 2 — Semantic match: A new NDA from a different company but same structure matches semantically. Only the changed fields are regenerated — you pay for the delta, not the whole extraction.

System 2 requires embeddings: pip install mnemon-ai[full] or set an OpenAI API key. System 1 alone covers exact repeats — still eliminates a large fraction of costs for templated workloads.
