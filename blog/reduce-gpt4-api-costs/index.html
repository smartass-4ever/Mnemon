GPT-4o costs $2.50 per million input tokens and $10 per million output tokens. At scale — 1,000 agent runs per day — that compounds to hundreds or thousands of dollars monthly. And most of that spend is on work the model has already done before.

Here are the three techniques that cut GPT-4o bills the most.

Technique 1: Cache executions (biggest win — 93% reduction)

Most production GPT-4o workloads have recurring patterns. The same classification logic. The same report template. The same question types. Every repeated call pays full GPT-4o price for reasoning the model already did yesterday.

Mnemon intercepts GPT-4o calls and returns cached results for similar inputs — 2.66ms instead of 15–30 seconds, zero tokens, $0.00.

pip install mnemon-ai
import mnemon
m = mnemon.init()

from openai import OpenAI
client = OpenAI()

def run_gpt4(goal, inputs, *_):
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[
            {"role": "system", "content": "You are an expert analyst."},
            {"role": "user", "content": f"{goal}: {inputs['data']}"}
        ]
    )
    return response.choices[0].message.content

result = m.run(
    goal="analyze and summarize quarterly earnings report",
    inputs={"data": "Revenue: $12.4M (+18% YoY). EBITDA margin: 22%..."},
    generation_fn=run_gpt4,
)
# Second call with same/similar report: 2.66ms, $0.00

Technique 3: Constrain output tokens

Output tokens cost 4× more than input tokens on GPT-4o ($10 vs $2.50 per million). If your prompts produce verbose outputs, you're paying a premium for words you don't need.

client.chat.completions.create(
    model="gpt-4o",
    max_tokens=150,  # hard cap
    messages=[{
        "role": "user",
        "content": "Classify this ticket. Reply with JSON only: {category, priority}. No explanation.\n\n" + ticket
    }]
)
