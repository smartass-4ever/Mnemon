SmolAgents from HuggingFace makes it easy to build code-first agents that can use tools, search the web, and reason over data. I built a research assistant with it — it scrapes, summarizes, and answers questions. But watching the API bill grow with each repeated query was a problem I needed to fix.

The issue is architectural: SmolAgents has no cross-run memory. Every agent.run() call spins up a fresh reasoning loop. The code your agent wrote to answer "what is the revenue breakdown of Acme Corp" last week gets thrown away entirely. Next week, same question — full cost again.

Where SmolAgents costs compound

  • Research agents answering recurring questions on updated data
  • Code agents that repeatedly generate the same data transformation scripts
  • Tool-using agents where tool selection logic is stable but inputs vary slightly
  • Multi-step pipelines where intermediate reasoning is reused across runs

Execution-level caching with Mnemon

Mnemon caches complete agent executions — the reasoning steps, tool calls, and final output — and replays them on similar future queries without touching the LLM.

pip install mnemon-ai
import mnemon
m = mnemon.init()

from smolagents import CodeAgent, HfApiModel

model = HfApiModel()
agent = CodeAgent(tools=[], model=model)

def run_research(goal, inputs, *_):
    return agent.run(f"{goal}: {inputs['query']}")

result = m.run(
    goal="summarize company financials",
    inputs={"query": "Acme Corp Q1 2026 revenue breakdown"},
    generation_fn=run_research,
)

print(result["output"])         # agent's answer
print(result["tokens_saved"])   # tokens saved this run
print(result["cache_level"])    # "system1" | "system2" | "miss"

Second call with the same or semantically equivalent query: 2.66ms, zero tokens, zero cost.

With OpenAI-backed SmolAgents

import mnemon
m = mnemon.init()

from smolagents import CodeAgent, OpenAIServerModel

model = OpenAIServerModel(model_id="gpt-4o")
agent = CodeAgent(tools=[], model=model)

def run_agent(goal, inputs, *_):
    return agent.run(inputs["task"])

result = m.run(
    goal="generate monthly sales analysis",
    inputs={"task": "Analyze and summarize sales data for May 2026"},
    generation_fn=run_agent,
)

How matching works

System 1 — Exact match: SHA-256 fingerprint of the full input. Identical query → cached result in ~2.66ms, zero tokens.

System 2 — Semantic match: "Q1 revenue for Acme" and "Acme Corp first quarter revenue" are the same question. Mnemon matches them semantically and replays the cached execution. You only pay for what genuinely changed.

System 2 requires embeddings: pip install mnemon-ai[full] or set an API key. System 1 alone still helps significantly for repeated queries.
