Agno (formerly Phidata) is a clean, production-ready framework for building AI agents with tools, memory, and structured outputs. I run an Agno-based financial research agent that monitors news and generates summaries. The quality is great. But paying for the same market analysis daily was burning budget I didn't need to spend.

The problem: Agno agents re-run their full reasoning loop on every agent.run() call. There's no cross-session execution cache. The agent re-reads, re-reasons, re-formats — even for topics it has analyzed dozens of times.

Where Agno costs accumulate

  • Scheduled research agents running recurring analysis tasks
  • Multi-tool agents with stable tool selection patterns across similar inputs
  • Team workflows where multiple agents repeatedly solve similar subtasks
  • Structured output agents extracting the same categories from similar documents

Execution-level caching with Mnemon

Mnemon wraps Agno agent runs and caches complete execution results for replay on semantically equivalent future inputs.

pip install mnemon-ai
import mnemon
from agno.agent import Agent
from agno.models.openai import OpenAIChat

m = mnemon.init()

research_agent = Agent(
    model=OpenAIChat(id="gpt-4o"),
    description="You are a financial research analyst.",
    instructions=["Summarize the key developments", "Focus on market impact"],
)

def run_research(goal, inputs, *_):
    response = research_agent.run(inputs["topic"])
    return response.content

result = m.run(
    goal="weekly fintech sector analysis",
    inputs={"topic": "Summarize key fintech developments for the week of May 26, 2026"},
    generation_fn=run_research,
)

print(result["output"])         # agent's analysis
print(result["tokens_saved"])   # tokens saved this run
print(result["cache_level"])    # "system1" | "system2" | "miss"

Second analysis on a similar topic: 2.66ms, zero tokens, zero cost.

With Agno Teams

import mnemon
from agno.team import Team

m = mnemon.init()
research_team = Team(agents=[analyst, writer, editor])

def run_team(goal, inputs, *_):
    response = research_team.run(inputs["brief"])
    return response.content

result = m.run(
    goal="produce market research report",
    inputs={"brief": "Q2 2026 SaaS market outlook"},
    generation_fn=run_team,
)

How matching works

System 1 — Exact match: Identical input → cached result in ~2.66ms, zero tokens.

System 2 — Semantic match: "Fintech week of May 26" and "Fintech developments May 26-30" match semantically. Only changed context triggers new LLM calls.

System 2 requires embeddings: pip install mnemon-ai[full] or set an API key.
