Fireworks AI offers fast, cost-effective inference for open-source models — Llama, Mixtral, Qwen, and others at a fraction of OpenAI pricing. I use it for a high-volume classification pipeline where speed and cost both matter. But even at Fireworks' competitive rates, recurring runs on the same input patterns were burning unnecessary tokens.

The issue: every API call is stateless. Fireworks doesn't cache your execution results cross-call. Each run is a fresh inference request.

Execution caching with Mnemon

pip install mnemon-ai
import mnemon
m = mnemon.init()

import openai  # Fireworks uses the OpenAI-compatible API

client = openai.OpenAI(
    api_key="your-fireworks-key",
    base_url="https://api.fireworks.ai/inference/v1"
)

def run_fireworks(goal, inputs, *_):
    response = client.chat.completions.create(
        model="accounts/fireworks/models/llama-v3p3-70b-instruct",
        messages=[{"role": "user", "content": f"{goal}: {inputs['text']}"}]
    )
    return response.choices[0].message.content

result = m.run(
    goal="classify document category and extract key entities",
    inputs={"text": "Invoice from Acme Corp for $4,200 dated May 2026..."},
    generation_fn=run_fireworks,
)

print(result["output"])
print(result["tokens_saved"])
print(result["cache_level"])

Second call with same or similar document: 2.66ms, zero Fireworks tokens, $0.00.

With LangChain + Fireworks

import mnemon
mnemon.init()

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="accounts/fireworks/models/llama-v3p3-70b-instruct",
    openai_api_key="fw_...",
    openai_api_base="https://api.fireworks.ai/inference/v1"
)
response = llm.invoke("Classify and summarize this support ticket")
# cache hit → 2.66ms, 0 tokens
